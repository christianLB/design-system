How to View the Showcases

The Vite dev server is running on port 5173. To view any showcase:

http://localhost:5173/[showcase-name].html

For example: http://localhost:5173/futuristic-finance.html

Each showcase automatically applies its theme and demonstrates real-world usage patterns.
